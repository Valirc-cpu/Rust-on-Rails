# Rust on Rails Starter Template

The official application skeleton for **Rust on Rails** projects (analogous to `laravel/laravel` in the PHP ecosystem).

## Features
- **Rails 8.1**: Modern, full-stack web framework with Propshaft, Turbo, and Stimulus.
- **In-Process Rust Engine**: Magnus 0.9 FFI with Ruby GVL release for multi-core computing.
- **Rayon Parallelism**: High-throughput batch processing and metrics reduction across all CPU cores.
- **Editorial UI**: Dark glassmorphic landing surface with live in-browser FFI benchmark widget.

## Getting Started
```bash
# If cloned standalone:
bin/setup
bin/railst s
```
