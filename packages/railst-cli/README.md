# `railst` CLI

The official command-line interface and installer for the **Rust on Rails** framework.

## Installation

### Via RubyGems
```bash
gem install railst
```

### Via One-Line Shell Script
```bash
curl -fsSL https://raw.githubusercontent.com/Valirc-cpu/Rust-on-Rails/main/install.sh | bash
```

## Quick Start

Create a new high-performance Rust on Rails application:
```bash
railst new my_app
cd my_app
railst s
```

Diagnose your system compiler and hardware environment:
```bash
railst doctor
```
